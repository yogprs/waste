# WasteWise - Aplikasi Deteksi Sampah (Waste Detection App)

## 🇬🇧 English

### Description
**WasteWise** is an AI-powered waste detection application designed to help users identify and classify waste materials instantly. Using computer vision and deep learning models, WasteWise bridges the gap between human intention and environmental reality by seamlessly identifying items like bottles, plastics, organics, and more. It helps individuals manage their waste better by viewing it as potential resources rather than just trash.

### Tech Stack
- **Backend Framework**: Python Flask, Flask-SocketIO
- **Frontend**: HTML5, CSS3, JavaScript (Jinja2 Templates)
- **Machine Learning & Vision**: TensorFlow, Keras, OpenCV, Numpy
- **Database & Cloud Storage**: Supabase (PostgreSQL for user data & history, Storage for images)
- **Security**: bcrypt (Password Hashing)

### Features
- **Live Detection**: Use your device's camera to get real-time waste classification and information via WebSockets.
- **Instant Recognition**: Upload photos and let the neural network identify the waste type and accuracy.
- **Detection History**: Save and view your past waste detection results, securely stored on the cloud.
- **User Authentication**: Secure Registration and Login functionalities for personalized history tracking.
- **Profile Management**: Update or delete user profile information and data easily.

## 🇮🇩 Bahasa Indonesia

### Deskripsi
**WasteWise** adalah aplikasi deteksi sampah berbasis kecerdasan buatan (AI) yang dirancang untuk membantu pengguna mengidentifikasi dan mengklasifikasikan material sampah secara instan. Menggunakan model *computer vision* dan *deep learning*, WasteWise menjembatani kesenjangan antara niat manusia dan realitas lingkungan dengan mengidentifikasi barang-barang seperti botol, plastik, organik, dan lainnya. Aplikasi ini membantu masyarakat mengelola sampah dengan lebih baik dengan melihatnya sebagai potensi sumber daya.

### Tech Stack (Teknologi yang Digunakan)
- **Backend Framework**: Python Flask, Flask-SocketIO
- **Frontend**: HTML5, CSS3, JavaScript (Jinja2 Templates)
- **Machine Learning & Vision**: TensorFlow, Keras, OpenCV, Numpy
- **Database & Cloud Storage**: Supabase (PostgreSQL untuk data pengguna & riwayat, Storage untuk gambar)
- **Keamanan**: bcrypt (Hashing Password)

### Fitur
- **Deteksi Langsung (Live Detection)**: Gunakan kamera perangkat Anda untuk mendapatkan klasifikasi dan informasi sampah secara *real-time* menggunakan WebSocket.
- **Pengenalan Instan (Instant Recognition)**: Unggah foto dan biarkan jaringan saraf (neural network) kami mengidentifikasi jenis sampah beserta tingkat akurasinya.
- **Riwayat Deteksi (History)**: Simpan dan lihat kembali hasil deteksi sampah Anda sebelumnya yang tersimpan dengan aman di *cloud*.
- **Autentikasi Pengguna**: Fitur Registrasi dan Login yang aman untuk menyimpan riwayat deteksi secara personal.
- **Manajemen Profil**: Memperbarui atau menghapus informasi profil pengguna dan data dengan mudah.
